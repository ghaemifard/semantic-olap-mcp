# OLAP MCP Server

An AI-native semantic analytics server that connects Large Language Models (LLMs) with OLAP systems through the Model Context Protocol (MCP).

The project provides a unified interface for:
- Cube metadata discovery
- Dimension and hierarchy exploration
- Measure analysis
- Natural language to MDX translation
- MDX query execution
- Multidimensional analysis operations (slice, dice, drill-down, roll-up)

Built with Java (Spring AI MCP), and modern data engineering principles.

## Project Status

This project is currently in an early development stage. 
The core architecture and main features are being actively implemented.

It is not production-ready yet and should be considered experimental.
APIs, features, and internal designs may change as the project evolves.
